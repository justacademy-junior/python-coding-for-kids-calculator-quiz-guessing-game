# Python Coding for Kids: Calculator, Quiz and Number Guessing Program

A playful, interactive landing page for **Python coding for kids**. Visitors can play three mini projects right in the browser, a calculator, a quiz and a number guessing game, then explore the free demo, programs, course and blog links.

## What is inside

- **Playable arcade.** A calculator with a sum tape, a five question quiz with progress dots, and a number guessing game with hearts and a fading number board that shows how every hint cuts the choices in half.
- **Pip the Python snake.** A friendly mascot whose eyes follow the pointer and who gives a new tip on every click or tab change.
- **Flip cards.** Five tiny coding ideas explained in kid friendly words: message, memory box, question, fork in the road and loop.
- **Coding path.** Four steps from a free demo to deeper Python training.
- **Link cards.** Every card is fully clickable and opens in a new tab.
- **FAQ with schema.** Parent questions with FAQPage structured data for search and AI answer engines.
- **Accessible.** Keyboard friendly tabs, visible focus, labelled controls and reduced motion support.

## Run it locally

No build step is needed. Download the repository and open `index.html` in any modern browser.

## Publish with GitHub Pages

1. Create a new repository and upload `index.html` and `README.md`.
2. Open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then press **Save**.
5. After a minute, your page will be live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Customise

- Change colours in the `:root` block at the top of the `<style>` section.
- Edit quiz questions in the `bank` list inside the script.
- Change the guessing range by editing the `20` values in the `newGame` and `guess` functions and the tile loop.
- Update links by searching for `https://` in `index.html`.
